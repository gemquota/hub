🔧 Architecture

RSIS implements a three-loop self-improvement architecture: L1 action loop (per-task planning/execution), L2 improvement loop (per-session code changes/evaluation), L3 evolution loop (cross-session memory consolidation/meta-strategies). The system uses an immutable AI evaluator with 4 evaluation phases.
